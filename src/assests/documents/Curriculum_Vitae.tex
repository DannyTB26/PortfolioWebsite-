\section*{Projects}
\project{Go Automation Document Collection System}{2026 -- Present}\\
A multi-tenant SaaS I am building single-handedly that lets firms collect, verify and reuse documents from their customers. Customers upload required documents through secure, no-login links; the system works out what each case needs, checks document freshness with AI extraction, and can automatically reuse a document a customer already supplied on an earlier case instead of re-chasing it. Built with Next.js, React, TypeScript and Supabase (PostgreSQL) with strict per-firm row-level security. I develop it through a proprietary workflow built around Claude Code and Codex: Claude Code works with full context of the entire application and its roadmap, while every feature is adversarially tested with Codex as soon as it is built, which has boosted my productivity enormously.

\vspace{6pt}
\project{Mortgage Bridge CRM}{2026}\\
A mobile-first Progressive Web App that gives mortgage brokers a fast, secure workflow over their existing CRM (GoHighLevel). I built the first version (an installable PWA with a lightweight Node backend, PostgreSQL storage, scrypt-hashed session authentication, role-based admin/broker access and web-push notifications) and now lead its ongoing development alongside a second developer.

\vspace{6pt}
\project{Lead-Integration Bridge}{2026}\\
A resilient webhook-to-CRM service that ingests leads from a third-party provider: it verifies each signature, fetches the full record over an authenticated API and maps it into a client's CRM. Built stateless and idempotent so retried deliveries never duplicate, and validated against the live systems rather than the documentation, which caught several spec inaccuracies that would otherwise have shipped silently.

\vspace{6pt}
\project{Regulated Site Launch}{2026}\\

\vspace{6pt}
\project{Legacy System Recovery}{2026}\\
Recovered design knowledge from an 18-month-old .NET application due for decommission with no source repository, reconstructing its logic and schema history from build artefacts and migration history and surfacing proven production content.
