\section*{Projects}
\project{Go Automation Document Collection System}{2026 -- Present}\\
A multi-tenant SaaS I am building single-handedly that lets firms collect, verify and reuse documents from their customers. Customers upload required documents mainly through WhatsApp, as well as email; the system determines what each case needs, checks document validity with AI, and can automatically reuse a document a customer already supplied on an earlier case instead of chasing it again. This was built with Next.js, React, TypeScript and Supabase (PostgreSQL) with strict per-firm row-level security. I'm developing it through a proprietary workflow built around Claude Code and Codex. Claude Code works with full context of the entire application and its roadmap, while every feature is rigorously tested with Codex as soon as it is built. This has boosted my productivity significantly.

\vspace{6pt}
\project{Mortgage Bridge CRM}{2026}\\
A mobile-first Progressive Web App that gives mortgage brokers a fast, secure workflow over their existing CRM in GoHighLevel. I built the first version as an installable PWA with a lightweight Node backend, PostgreSQL storage, scrypt-hashed session authentication, role-based admin/broker access and web-push notifications. Now I lead its ongoing development alongside a second developer.

\vspace{6pt}
\project{Lead-Integration Bridge}{2026}\\
A resilient webhook-to-CRM service that ingests leads from a third-party provider. It verifies each signature, fetches the full record over an authenticated API and maps it into a client's CRM. Built stateless and idempotent so duplicate deliveries never happen. This was also validated against the live systems rather than the documentation, which caught several spec inaccuracies that would otherwise have shipped incorrectly.

\vspace{6pt}
\project{Regulated Site Launch}{2026}\\
Took an FCA-regulated brokerage's website live and hardened it with security headers (HSTS, CSP, clickjacking and referrer policies). I also self-hosted its assets, verified the required regulatory disclosures, and performed a zero-downtime DNS cutover over the client's live email.

\vspace{6pt}
\project{Legacy System Recovery}{2026}\\
Recovered design knowledge from an 18-month-old .NET application due for decommissioning with no source repository. I was able to reconstruct its logic and data model from old build artefacts and migration history, identifying which production behaviour was worth preserving. This delivered a prioritised backlog of which past decisions were worth carrying into the successor system.
