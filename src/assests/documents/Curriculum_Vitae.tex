\section*{Projects}
\project{Go Automation Document Collection System}{2026 -- Present}\\
A multi-tenant SaaS I am building single-handedly that lets firms collect, verify and reuse documents from their customers. Customers upload required documents through secure, no-login links; the system works out what each case needs, checks document freshness with AI extraction, and can automatically reuse a document a customer already supplied on an earlier case instead of re-chasing it. Built with Next.js, React, TypeScript and Supabase (PostgreSQL) with strict per-firm row-level security.

\vspace{6pt}
\project{Mortgage Bridge CRM}{2026}\\
A mobile-first Progressive Web App that gives mortgage brokers a fast, secure workflow over their existing CRM (GoHighLevel). I built the first version (an installable PWA with a lightweight Node backend, PostgreSQL storage, scrypt-hashed session authentication, role-based admin/broker access and web-push notifications) and now lead its ongoing development alongside a second developer.

\vspace{6pt}
\project{NEA Game Project}{January 2023 -- February 2024}\\
I created a 2D game for my A-level Computer Science project which involved using object-oriented programming techniques as well as the game engine Godot. Everything, including character design, code, and level design, I did by myself using the specified game engine as well as Aseprite to create pixelated sprites.

\vspace{6pt}
\project{AI Interface for Three}{June 2023}\\
